# Unreal Editor MCP

A new iteration of a Model Context Protocol (MCP) server for Unreal Engine, intended for use with frontier LLM models and updated LLM harness tooling.

This project starts from a clean implementation and will draw on knowledge gained from the previous iteration. Requirements, architecture, and implementation details will be defined as development progresses.

The workspace is currently in initial setup. [AGENTS.md](AGENTS.md) directs LLM agents to the [workflow index](docs/workflow/index.md), which routes tasks to the relevant workflow guides as they are added.
