# Documentation workflow

The `docs/` folder and every subfolder within it must contain an `index.md` file.

Each index must:

- Describe the contents and purpose of its folder.
- List every other documentation file and every immediate subfolder in that folder, with a brief description of each entry.
- Use relative links to documentation files and to each subfolder's `index.md`.

When creating a documentation folder, create its index and add the folder to its parent's index. When adding, changing, moving, renaming, or deleting documentation, update the affected indexes so their descriptions, entries, and links remain accurate.

Keep workflow guide routing in `docs/workflow/index.md` complete, including a description of when each guide should be read.
