# Project workflow

This directory contains project workflow guides for LLM agents.

Before starting a task, review the guide list below and read the guides relevant to the current task, using their descriptions to decide which apply. If the task changes, read any additional guides that become relevant before continuing that work.

## Workflow guides

- [Documentation](documentation.md): Read when creating, editing, moving, renaming, or deleting documentation files or folders under `docs/`.

Keep this list complete as guides are added, renamed, or removed. List every other workflow guide with a link relative to this file and a short description of when to read it.
